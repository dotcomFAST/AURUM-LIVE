# Aurum Live — Mobile-first Live Roulette Concept

UI/UX case study with an interactive prototype. Single file, no build step.

## Run locally
Open `index.html` in a browser.

## Edit
At the bottom of `index.html`, change the `CONFIG` block:
- `email` — your email
- `portfolioUrl` — link to your portfolio (set to https://www.bohdan-designer.site/)

## Images (optional)
Put two files in `assets/`:
- `assets/dealer.jpg` — 16:9, at least 1920×1080, dealer centred
- `assets/table.jpg` — square, at least 600×600

Without them the site shows an illustrated roulette wheel instead.

## Deploy to GitHub Pages
1. Create a public repo, e.g. `aurum-live`.
2. Upload `index.html`, `README.md` and the `assets/` folder.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root → Save.
4. In about a minute the site is live at `https://<username>.github.io/aurum-live/`.

Concept project. "Aurum" is a fictional brand. 18+
